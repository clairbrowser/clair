# Which review section owns each tracked file: "<section id or -> <glob>".
# The first rule that matches a path wins, "-" excludes the path, and "*" also
# matches "/". `scripts/review.sh check` fails when a tracked file matches no
# rule.
#
# Source files are listed one by one on purpose. A new source file then fails
# the check until someone decides which reviewer reads it, where a catch-all
# would hand it to the wrong one without anyone noticing. A section holds both
# halves of a feature, C++ and Swift, so its reviewer sees each side of the
# ClairHost.h contract.
